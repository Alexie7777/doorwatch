HeroUI 是什么

React 的组件库（NextUI 改名而来），Tailwind 做的，配色、圆角、阴影有固定规范。 看板这种「状态 + 时间 + 一个二维码」的页面，正好是它的甜点区。

用到的组件

Card Chip Button Divider Progress Avatar Dark mode

真把 React 换上去，代价

  • × 前端从「零构建静态文件」变成要跑 vite，Dockerfile 得加一步
  • × 产物带哈希，Service Worker 的预缓存清单要重做
  • × 体积从几十 KB 涨到几百 KB，framer-motion 就占一大半
  • ✓ 换来成套组件、暗色模式开箱即用，以后加交互不用手写
